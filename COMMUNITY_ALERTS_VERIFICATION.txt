🔌 API ENDPOINTS

Implemented:
✅ POST   /api/auth/community-alert/broadcast/
          - Create and broadcast alert
          - Payload: alert_type, message, latitude, longitude, radius_km
          - Returns: alert_id
          - No auth required

✅ GET    /api/auth/community-alert/nearby/
          - Get alerts within search radius
          - Params: latitude, longitude, radius (km)
          - Returns: Alert list with distances
          - No auth required

✅ POST   /api/auth/community-alert/<id>/report/
          - Report spam/false alert
          - Auto-deactivates at 5 reports
          - Returns: success status
          - No auth required
