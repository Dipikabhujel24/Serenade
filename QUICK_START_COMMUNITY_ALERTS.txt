# 🚀 COMMUNITY ALERTS - QUICK START REFERENCE

## What Was Built
A real-time safety alert system where users broadcast danger warnings to nearby users within a customizable radius (3-15 km). Similar to Waze but for personal safety.

## API Endpoints (3 Total)

```
POST   /api/auth/community-alert/broadcast/     → Create alert
GET    /api/auth/community-alert/nearby/        → Get nearby alerts
POST   /api/auth/community-alert/<id>/report/   → Report spam
```

## Core Features

✅ **Broadcast** - Users send alerts with type, message, location, radius
✅ **Real-time** - WebSocket updates to connected users instantly
✅ **Geospatial** - Haversine formula filters nearby alerts
✅ **Smart** - Auto-expire (1 hour), report spam (5-report deactivation)
✅ **Offline-ready** - Works with anonymous users

## Testing

1. **Broadcast an alert**
   - Open CommunityAlertsPage
   - Tap FAB button (🚨)
   - Fill form and submit

2. **Receive alert**
   - Open on second device
   - Alert appears in real-time (no refresh)

3. **Report spam**
   - Tap "Report" on any alert
   - After 5 reports, alert deactivates

## WebSocket Flow

```
User 1: Broadcasts alert
   ↓
Backend: Creates CommunityAlert model
   ↓
Channels: Broadcasts to "community_alerts" group
   ↓
All connected users: Receive message in real-time
   ↓
User 2: Distance checked, alert added to list
   ↓
UI: Updates instantly, no refresh needed
```

## Troubleshooting

**WebSocket not connecting?**
→ Check Channels is configured, Daphne is running

**Alerts not appearing?**
→ Check location permission, alert hasn't expired (1h max)

**Broadcast crashes?**
→ Check message is not empty, location is available
